# VOLLEYBALL DUEL DX

ブラウザで遊べる、レトロアーケード風の 1on1 バレーボール対戦ゲームです。

**▶ プレイ:** https://yu110tno89-netizen.github.io/volleyboll/

原作: [mc-765lt/volleyboll](https://github.com/mc-765lt/volleyboll)（このリポジトリはその改良版です）

## 遊び方

| | 移動 | ジャンプ・スパイク | レシーブ・トス | キャラ固有スキル |
|---|---|---|---|---|
| P1（左） | A / D | W | S | Q |
| P2（右） | J / L | I | K | U |

- 移動キーの2回押しでダイブ
- ボールに触れると自動でレシーブ、2打目はネット際へトス、3打目はジャンプしてスパイク
- 当たる直前に押すと「JUST MEET」で強打

## モード

- **2P VS**：1台のキーボードで2人対戦
- **CPU EASY / NORMAL / HARD**：CPU 対戦（CPU もキャラ固有の技を使います）
- CPU モードのスタート画面で P2 のキーを押すと、2P 対戦に切り替わります（乱入）
- 得点（5 / 11 / 15 / 21 / 25）とデュースの有無を選べます
